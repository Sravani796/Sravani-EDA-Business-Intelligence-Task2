# House Price Exploratory Data Analysis & Business Intelligence Project

## Introduction

This project was completed as part of the ApexPlanet Data Analytics Internship Program.

The objective of this task was to perform Exploratory Data Analysis (EDA) on cleaned housing data to identify market trends, business insights, and key performance indicators through statistical analysis, visualizations, and SQL queries.

---

## Project Goals

* Analyze cleaned housing dataset
* Generate descriptive statistics
* Identify pricing patterns and trends
* Explore relationships between variables
* Develop business-focused SQL queries
* Create visual reports
* Design a dashboard KPI mockup

---

## Technologies Used

* Python
* Pandas
* Matplotlib
* SQL

---

## Project Structure

* `eda_analysis.py` → Performs statistical analysis and visualizations
* `business_queries.sql` → SQL queries for business intelligence insights
* `dashboard_mockup.md` → KPI dashboard planning
* `cleaned_housing_data.csv` → Processed dataset from Task 1

---
